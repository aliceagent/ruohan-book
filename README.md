# 聊天聊不完 · Chat Without End

A Next.js study companion for 解丽琪 (Shelley Hsieh), *聊天聊不完：120个中文情境3600道会话题* (新学林, 2023).

Units 1–4 are live: every scene, dialogue, stretch-vocabulary list, and interactive question from those units, with pinyin and English added for learners.

## What’s in this repo

- Lesson pages at `/units/1/1-1` … `/units/4/4-7`
- Catalog of all 22 units (later units listed, not yet transcribed)
- Study desk: search, flashcards, glossary, local progress
- Official dialogue MP3s for Units 1–4 on each lesson and at `/audio`
- [Website plan](/plan)

This is a learner companion, not a scan of the PDF.
